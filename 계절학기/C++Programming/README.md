# C++ Programming (계절학기)

C++ 기초 문법을 익히는 계절학기 수업으로, 매 과제마다 교재 예제를 기반으로 코드를 완성하고 실행 결과를 예측하는 형식으로 진행됩니다.

## 다룬 주제 (과제 1~22, 중간·기말 범위)
- 조건문(if / else if) — 예: 점수 구간별 등급 판정(상/중/하/낙제), BMI 계산, 누진세율 계산
- 반복문(for / while) — 패턴 출력, 누적합 계산 등
- 기본 입출력 및 변수/자료형

## 제출 형식
과제는 "교재 예제의 실행 결과 예측 + 빈칸(조건식) 채우기" 형식으로 구성되어, 조건문/반복문의 동작 원리를
직접 손으로 추론하며 학습했습니다. (교재 기반 과제 특성상 원문 코드는 이 저장소에 올리지 않았습니다.)
