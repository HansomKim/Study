# 자료구조실습 (Data Structures Lab)

C++로 자료구조를 구현하고, 매주 백준(BOJ) 문제 3문제를 풀어 코드·실행 결과 화면을 함께 제출하는 실습 수업입니다.
2~13주차까지 매주 실습 코드와 제출 보고서를 작성했고, 기말 범위 전체를 정리한 핵심노트를 별도로 만들었습니다.

## 다룬 문제 예시
- 2557번 Hello World, 8393번 합 구하기 등 기초 문법 문제
- 반복문을 활용한 패턴 출력(예: 소용돌이 모양 출력) 문제
- 이후 주차로 갈수록 스택/큐/트리 등 자료구조를 응용한 문제로 난이도 상승

## 제출 형식
과제 보고서는 "문제 화면 + 제출 코드 화면 + 채점 결과(성공) 화면" 3종 캡처를 포함하는 형식으로 제출했습니다.
(이미지 기반 보고서라 이 저장소에는 별도 첨부하지 않았습니다 — 필요시 원본 PDF를 요청해주세요.)

*기말 핵심노트(정렬/탐색/스택/큐/트리 등 이론 정리)는 추후 텍스트로 재정리해 업로드할 예정입니다.*
