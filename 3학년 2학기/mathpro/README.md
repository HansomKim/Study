# mathpro (수학적 프로그래밍, Mathematical Programming)

Python으로 수학적 개념(벡터·행렬 연산)부터 알고리즘·자료구조(정렬, 탐색, 시간복잡도)까지
직접 구현하며 익히는 수업입니다. 매 과제는 "문제당 파일 1개, 순수 파이썬(모듈/생성형 AI 사용 금지), 100줄 이내" 규칙으로 진행됩니다.

## 다룬 내용
- **1~6주차 / 중간고사**: 벡터·행렬 기본 연산 직접 구현 — 벡터 생성, 행렬 덧셈/곱셈, 단위행렬·대각행렬 생성,
  행렬 동치 판별 등을 라이브러리 없이 순수 함수로 작성 (`week1-6.py`, `mid2~4.py`)
- **9~14주차 / 기말고사**: 정렬 알고리즘과 시간복잡도 — 선택정렬, 버블정렬, 삽입정렬, 병합정렬(O(n log n))을
  직접 구현하고 Big-O 표기법으로 효율성을 비교 (`#week9.py` ~ `#week9-14.py`)
- **퀴즈 & 기말 예제**: 백준(BOJ) 스타일의 정렬·탐색 응용 문제 풀이 (`quiz2.py`, `예제문제 전체 모음.py`, `#final1~6.py`)
