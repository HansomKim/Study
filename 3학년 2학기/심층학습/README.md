# 심층학습 (Deep Learning)

## 팀 프로젝트 — 실시간 의료 서비스 혼잡도 예측을 위한 딥러닝 모델 최적화 연구
📄 **KSC 2025 (한국정보과학회 학술대회) 논문 게재·발표**
공동저자: 김한솜(제1저자), 나유진, 오윤지, 이예림 — 성신여자대학교 AI융합학부

### 문제의식
의료진 파업·진료 지연으로 응급실 혼잡도가 사회적 이슈가 되는 상황에서, 기존 연구는 대부분 일/주 단위의
통계적 회귀분석(ARIMA 등)에 머물러 실시간 대응에 한계가 있었습니다.

### 접근 방법
- **Synthetic Time Series 생성**: 연도·시간대별 집계만 제공되는 공개 응급의료통계(2019–2023, 서울시)를
  연간 총합은 보존하면서 3시간 단위 시계열로 재구성 (표본 400개로 증강)
- **특성공학**: 시간대에 사인/코사인 변환을 적용해 24시간 주기성을 반영, 재실시간·중증환자 수를 통합한
  혼잡도 종합 지표 설계
- **모델 비교**: LSTM / GRU / CNN-LSTM 비교 → **CNN-LSTM이 RMSE 0.131로 최저 오차** 달성
  (CNN이 단기 국소 패턴을, LSTM이 장기 의존성을 포착하는 하이브리드 구조)
- 후속 실험에서는 CNN-LSTM, RandomForest, XGBoost를 비교했고, 제한된 데이터 환경에서는
  **XGBoost(MAE 59, RMSE 68)** 가 도메인 지식 기반 특성공학과 결합했을 때 더 실용적인 대안임을 확인

### 의의
장기 추세와 단기 변동을 동시에 반영하는 실시간 예측 파이프라인을 제안했고, 제한된 공공데이터 환경에서
복잡한 딥러닝보다 특성공학 + 트리 기반 모델 조합이 더 실질적인 최적화 대안이 될 수 있음을 시사했습니다.
